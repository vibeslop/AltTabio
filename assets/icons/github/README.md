# GitHub mark

`mark-github.svg` is the GitHub mark from [GitHub Octicons](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg), distributed under the adjacent MIT license.

The generated Windows icons contain the same mark at 16, 18, 20, 24, 28, 32, 36, 40, 48, and 64 pixels, with neutral light and dark fills. They are embedded in the executable; the app loads no network assets.

Regenerate them with `uv run scripts/windows/build-github-icons.py`. The rasterizer is a development tool, not an application dependency.
