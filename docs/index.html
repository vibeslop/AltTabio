About the permission prompt

When AltTabio starts, Windows asks for permission. That one approval is what lets it respond to the Alt+Tab keys before Windows does — and close a frozen program for you when you ask it to. It's needed for the job, not for anything sneaky.

Changed your mind? No problem.

AltTabio doesn't install itself deep into Windows. It lives in one folder, and its settings live right next to it. Delete the folder and it's completely gone — no leftovers, no uninstaller needed.

Good questions.

Is it really free? What's the catch?

There isn't one. AltTabio is free, open-source software — made to be useful, not to make money. No trial, no ads, no account, no "premium" version.

Will it slow down my computer?

No. It's a single small program built specifically for Windows, and it sits quietly until you press Alt+Tab. There's no background syncing, updating, or phoning home — because it has no internet connection at all.

Does it collect any of my data?

None. AltTabio contains no analytics and no networking whatsoever — it couldn't send your data anywhere even if it wanted to. And because the source code is public, anyone can verify that.

Why does Windows ask for permission when it starts?

That approval lets AltTabio respond to Alt+Tab before Windows does, and lets it close a frozen program when you ask. Those are the only reasons — and both are things you can check in the public source code.

What if I want the old Alt+Tab back?

Right-click the AltTabio icon in your system tray and choose Exit — Windows instantly goes back to normal. You can also keep AltTabio on Alt+Tab but leave Win+Tab alone, or the other way around.

How do I uninstall it?

Turn off "start with Windows" if you enabled it, exit from the tray icon, and delete the folder. That's everything — it leaves nothing behind.

Which computers does it work on?

Any modern 64-bit Windows PC — which is nearly every Windows computer sold in the last decade. It handles multiple monitors and high-resolution displays properly, too.
