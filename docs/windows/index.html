What changes when you press Alt+Tab.

  • Numbered windows

    Press 1 to 9 and you're on that window, with no stepping through thumbnails.

  • Large live preview

    See the selected window alone, or in its place on the full desktop.

  • Type to filter

    Start typing while you hold Alt. The list narrows by title, app, or number.

  • The shortcut you know

    Alt+Tab opens it and letting go of Alt switches. Win+Tab can open it too.

  • Fix a stuck window

    F4 closes it, F5 to F7 minimize, maximize, and restore, and F8 ends a frozen program.

  • Works across monitors

    It scales per monitor, and can list only the windows on the one you're using.

Install

Download, unzip, run

  1. Get the Windows zip from GitHub Releases.
  2. Unzip it into a folder you'll keep, such as C:\Program Files\AltTabio.
  3. Open AltTabio.exe, click Yes on the Windows prompt, and press Alt+Tab.
Download for Windows
Before you turn on start with Windows

Keep it in a safe folder

Start with Windows creates a scheduled task that runs AltTabio with the highest privileges at every logon. If a program without administrator rights could replace AltTabio.exe, it could use that task to gain them.

So move AltTabio to a folder only administrators can change, such as Program Files, before you turn the option on.

Uninstall

Turn off start with Windows if you enabled it, choose Exit from the tray icon, and delete the folder. The settings file lives in that folder, so nothing else is left.

Questions

About AltTabio on Windows. The main page covers price and privacy.

Why does Windows ask for administrator permission?

AltTabio needs it to see Alt+Tab before Windows does and to close a frozen program when you ask. Those are the only reasons.

Can I keep Win+Tab as Task View?

Yes. AltTabio replaces Alt+Tab and Win+Tab separately, so you can keep either one as Windows made it.

Does it work with several monitors and high-DPI displays?

Yes. It scales per monitor, and it can list only the windows on the monitor you are using.

How do I get the Windows Alt+Tab back?

Right-click the AltTabio icon in the system tray and choose Exit. Windows goes back to its own switcher at once.

How do I uninstall it?

Turn off start with Windows if you enabled it, exit from the tray icon, and delete the folder. The settings file lives in that folder, so nothing is left behind.

Is this an Alt+Tab Terminator alternative?

Yes. AltTabio is an independent, open-source window switcher for people who want a list and a live preview on Alt+Tab. It is not affiliated with Alt+Tab Terminator.
