Getting started

AltTabio is a free, open-source window switcher. It replaces Alt+Tab on 64-bit Windows 10 and 11, and Cmd+Tab on macOS 26 and later. It keeps the shortcut you already know and shows you more once the switcher is open.

On Windows, Alt+Tab opens a list of your open windows beside a large live preview of the selected one. Start typing while you hold Alt and the list narrows by title, app, or number. Letting go of Alt switches.

Runs on
64-bit Windows 10 and 11, with several monitors and high-DPI displays
Comes as
One small program, installed with one line in PowerShell. No store account, no runtime.

Install on Windows

Paste one line into PowerShell. AltTabio updates itself after that.

Install with PowerShell Recommended

> irm https://vibeslop.github.io/AltTabio/install.ps1 | iex
  1. Press Start, type PowerShell, and open it. Paste the line and press Enter.
  2. Windows asks whether PowerShell may make changes. Choose Yes. A second window finishes the install and opens AltTabio.
  3. Press Alt+Tab.

The script downloads the newest release and installs it only if it is signed with AltTabio’s pinned release key, the same check the app’s updater makes. It installs in C:\Program Files\AltTabio, a folder only administrators can change, and keeps your settings when it updates a copy there.

Why PowerShell? The certificate that stops Windows warning about an app costs its developer a yearly fee, and AltTabio doesn’t pay it, so Windows warns about a copy downloaded in a browser. The command checks that the download really is AltTabio’s, then installs it.

Download and verify by hand

  1. Get the Windows zip and its matching .zip.minisig from the same GitHub release.
  2. Follow Windows first-install verification. Build the verifier from separately trusted source, never from the downloaded archive, and verify the archive and signed release identity. Stop if the signature is missing or verification fails.
  3. After verification succeeds, unzip that archive into a folder only administrators can change, such as C:\Program Files\AltTabio.
  4. Open AltTabio.exe, click Yes on the Windows prompt, and press Alt+Tab.

Windows asks for administrator permission because AltTabio needs it to see Alt+Tab before Windows does and to close a frozen program when you ask. More about the prompt.

Keep it in a safe folder

Start at sign-in creates a scheduled task that runs AltTabio with the highest privileges at every logon. If a program without administrator rights could replace AltTabio.exe, it could use that task to gain them.

So keep AltTabio in a folder only administrators can change, such as Program Files. Both autostart and the updater refuse an executable that non-elevated processes can replace.

Install on Mac

Paste one line into Terminal. AltTabio updates itself after that.

Install with Terminal Recommended

$ curl -fsSL https://vibeslop.github.io/AltTabio/install.sh | sh
  1. Open Terminal, paste the line, and press Return. It installs AltTabio in Applications, or updates your copy, then opens it.
  2. Allow Accessibility when AltTabio asks, then press Cmd+Tab.
  3. AltTabio updates itself from then on. To check now, choose Check for Updates… in its menu bar menu.

The script downloads the newest installer and runs it only if it is signed with AltTabio’s pinned release certificate. A new copy goes in /Applications if that folder is writable, otherwise in ~/Applications. An existing copy is updated where it is.

Why Terminal? Apple charges developers to notarize their apps, and AltTabio doesn’t pay, so macOS blocks a copy downloaded in a browser. The command checks that the download really is AltTabio’s, then installs it.

First run

AltTabio asks for Accessibility on first launch, keeps its settings window open until you allow it, and picks up the grant while it runs. After your first Cmd+Tab it asks for Screen Recording, which only window previews use. The list works without it. More about both permissions.

Download the app by hand

  1. Download AltTabio-<version>-macos.zip from GitHub Releases and unzip it in Downloads. Leave the app there without opening it.

  2. In Terminal, run this command to verify the app’s signature, bundle identifier, and pinned release certificate. If you unzipped it elsewhere, change the quoted app path to that location.

    $ codesign --verify --deep --strict -R '=identifier "com.vibeslop.AltTabio" and certificate leaf = H"617A82407E9767025EDE4A62A9B990ADEA21F53B"' "$HOME/Downloads/AltTabio.app" && printf '%s\n' 'Verified AltTabio release identity.'

    Continue only if Terminal prints Verified AltTabio release identity. If it does not, stop. Do not move or open the app, or use Open Anyway.

  3. Only after verification succeeds, move that same AltTabio.app to Applications and open it. When macOS says it could not verify the app, choose Done.
  4. For the verified app only, open System Settings, Privacy & Security, click Open Anyway next to the message about AltTabio, and confirm.

Open Anyway does not verify the release identity; the check in step 2 is required first. The Terminal installer checks the same identity before installing.

Language

The interface is in English, Russian, and Simplified Chinese. Choose a language in Settings, or leave System selected to use the first supported language in your system’s preferred languages, with English as the fallback.

On Windows, a new language shows at once and is kept with Save changes; Cancel restores the previous one.

On a Mac, the change applies immediately.

Permissions

Administrator rights

Windows asks for administrator permission when AltTabio starts. AltTabio needs it to see Alt+Tab before Windows does and to close a frozen program when you ask. Those are the only reasons.

Start at sign-in runs AltTabio with those rights at every logon, which is why it needs a safe folder. F9 opens another window of an app without them.

On a Mac, AltTabio asks for two permissions, for two jobs. Both live in System Settings, Privacy & Security.

Accessibility

Lets AltTabio see Cmd+Tab before macOS does, and raise, minimize, and close windows. AltTabio asks for it on first launch, keeps its settings window open until you allow it, and picks up the grant while it runs.

Screen Recording, only for previews

AltTabio asks for it after your first Cmd+Tab, and not at all with Show window previews off. Without it the list still works, and the preview area shows a hint instead. Once you allow it, macOS offers to quit and reopen AltTabio so the capture sees the change.

Kept across updates

macOS ties both grants to the certificate an app is signed with. Every AltTabio release carries the same one, so an update never asks again.

Remote desktops and virtual machines

Apps such as Windows App, Parallels, and VMware take Cmd+Tab for their guest. AltTabio moves back in front of them whenever the front app changes, so Cmd+Tab keeps opening AltTabio inside them.

The one exception is secure keyboard input, which macOS reserves for one app while a password field holds it.

Updates

Release builds check GitHub for updates and install them on their own. Update requests contain no window titles, query text, previews, or settings. You can turn automatic updates off in Settings and still check by hand.

On Windows, AltTabio checks about a minute after startup and then daily. It downloads newer releases, verifies the archive’s Minisign signature and GitHub’s SHA-256 digest, and restarts after five minutes without keyboard or mouse input, once the switcher and dialogs are closed. Your settings and startup task are preserved.

To check yourself, choose Check for Updates or Update status in the tray menu, then Install and restart or Restart now in the status window. The updater refuses an executable that non-elevated processes can replace, so it needs a safe folder.

Ordinary Windows builds from source do not check for or install published updates. Update behavior, trust, and upgrade notes.

On a Mac, AltTabio looks for a newer release once a day, installs it, and reopens while the Mac is idle. To check now, choose Check for Updates… in its menu bar menu. That still works with Update automatically off.

Running the install command again also updates your copy. Updates never ask for the permissions again, because every release is signed with the same certificate.

Uninstall

  1. Turn off Start at sign-in if you enabled it.
  2. Choose Exit from the tray icon.
  3. Delete the folder. The settings file lives in it, so nothing else is left.

Get the Windows switcher back for now

Right-click the AltTabio icon in the system tray and choose Exit. Windows goes back to its own switcher at once. To give back only one shortcut, turn off Replace Alt+Tab or Replace Win+Tab.

  1. Turn off Launch at login in the settings.
  2. Quit AltTabio from its menu bar icon.
  3. Delete AltTabio.app.

  4. Remove its settings and permissions:

    $ rm -rf ~/Library/Application\ Support/AltTabio && tccutil reset All com.vibeslop.AltTabio

Get the system Cmd+Tab back for now

Turn off Replace ⌘ Tab in the AltTabio settings, or quit AltTabio from its menu bar icon.
