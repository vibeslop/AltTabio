AltTabio for Mac

Cmd+Tab straight to the window you want.

The Mac switcher stops at apps. AltTabio keeps Cmd+Tab and lists every window of the selected app, including minimized ones and ones on other desktops.

$ curl -fsSL https://vibeslop.github.io/AltTabio/install.sh | sh

Paste into Terminal. macOS 26 or later, Apple silicon and Intel. Free and open source. Or download the app.

What changes when you press Cmd+Tab.

Every window
Minimized windows, hidden apps, and windows on other desktops are in the list, each marked.
Your habits still work
The first Tab lands on the previous app, and letting go of Cmd switches.
Numbered windows
Press 1 to 9 to switch to that window of the selected app.
Act from the list
W, M, H, and Q close, minimize, hide, or quit. Force Quit is a right-click away.
Live preview
Turn on window previews to see the selected window. The list works without them.
Works in remote desktops
Cmd+Tab keeps opening AltTabio inside Windows App, Parallels, and VMware.

Two permissions, for two jobs.

Both live in System Settings, under Privacy & Security.

Accessibility

Lets AltTabio see Cmd+Tab before macOS does, and raise, minimize, and close windows. AltTabio asks for it on first launch, keeps its settings window open until you allow it, and picks up the grant while it runs.

Screen Recording, only for previews

AltTabio asks for it after your first Cmd+Tab, and not at all with Show window previews off. Without it the list still works. Once you allow it, macOS offers to quit and reopen AltTabio so the capture sees the change.

Kept across updates

macOS ties both grants to the certificate an app is signed with. Every AltTabio release carries the same one, so an update never asks again.

Remote desktops and VMs

Apps such as Windows App, Parallels, and VMware take Cmd+Tab for their guest. AltTabio moves back in front of them whenever the front app changes. The one exception is secure keyboard input, which macOS reserves for one app while a password field holds it.

Settings, if you want them.

Open them from the menu bar icon. They are saved in ~/Library/Application Support/AltTabio.

  • Replace ⌘ Tab
  • Also open with ⌥ Tab
  • Show window previews
  • Only windows on the current display
  • Launch at login
  • Update automatically
  • System, light, or dark appearance

Install, update, remove.

One line for each of the first two.

Recommended

Paste one line into Terminal

$ curl -fsSL https://vibeslop.github.io/AltTabio/install.sh | sh
  1. The script downloads the newest release, checks its signature, puts AltTabio.app in /Applications (or in ~/Applications when your account can't write there), and opens it.
  2. Allow Accessibility when AltTabio asks, then press Cmd+Tab.
  3. AltTabio updates itself from then on, and Check for Updates… in its menu bar menu looks right away. Running the same line again updates it too. If an update fails partway, the installed copy stays as it was.
By hand

Download the app

  1. Download AltTabio-<version>-macos.zip from GitHub Releases and unzip it.
  2. Move AltTabio.app to Applications and open it. When macOS says it could not verify the app, choose Done.
  3. Open System Settings, Privacy & Security, click Open Anyway next to the message about AltTabio, and confirm.

macOS asks because AltTabio is not notarized by Apple, which takes a paid developer account. The Terminal line avoids the question.

Uninstall

Remove it and its permissions

Turn off Launch at login in the settings, quit AltTabio from its menu bar icon, and delete AltTabio.app. Then remove its settings and permissions:

$ rm -rf ~/Library/Application\ Support/AltTabio && tccutil reset All com.vibeslop.AltTabio

Questions

About AltTabio on the Mac. The main page covers price and privacy.

Which Macs does it run on?

Any Mac with macOS 26 or later. The download is a universal app for Apple silicon and Intel.

Why does it need Accessibility and Screen Recording?

Accessibility lets AltTabio see Cmd+Tab before macOS does and raise, minimize, and close windows. Screen Recording is only for window previews, and AltTabio asks for it after your first Cmd+Tab. Without it the list still works, and the preview area shows a hint instead.

Do I have to grant the permissions again after an update?

No. macOS ties the permissions to the certificate an app is signed with, and every AltTabio release is signed with the same one.

Why is it installed with a Terminal command?

AltTabio is not notarized by Apple, which takes a paid developer account, so macOS blocks a copy downloaded in a browser. A copy downloaded with curl, as the script does, is not blocked. The script checks the signature before it installs anything, and you can read it first.

How do I get the system Cmd+Tab back?

Turn off Replace ⌘ Tab in the AltTabio settings, or quit AltTabio from its menu bar icon.

Does it collect any data?

No. The app has no analytics. It goes online only to look for updates on GitHub once a day, which Update automatically in the settings turns off. Previews are drawn on your Mac and never saved or sent anywhere.
